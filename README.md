UBER RIDE DATA ANALYSIS

Dashboard focus: Uber ride bookings, cancellations, peak hours, pickup locations, and cancellation reasons.

Key KPIs

| Metric                |       Value |
| --------------------- | ----------: |
| Total Rides           | **148,767** |
| Cancelled Rides       |  **37,427** |
| Cancellation %        |  **25.00%** |
| Average Rides per Day |     **412** |

These are the main KPIs reported in the project.

Analysis covered

The dashboard analyzes:

-Booking status distribution

-Peak-hour ride demand

-Top 10 pickup locations

-Cancellation reasons

-Overall ride performance

Key insights

-Completed rides: 62.21%

-Overall cancellation rate: 25.00%

-Driver cancellations: 18.12%

-Customer cancellations: 7.06%

-Demand increases during major peak-hour periods.

-Khandasa and Barakhamba Road are among the highest-volume pickup locations.

-Tools used

Tableau, Data Analysis, Data Visualization, and GitHub.

Project objective

The objective is to analyze Uber ride-booking data and create an easy-to-understand dashboard showing ride demand patterns, cancellation trends, and high-volume pickup locations.

Future improvements

The project suggests adding:

Revenue/fare analysis, driver performance, customer behavior, geographic heatmaps, date/location filters, monthly/weekly cancellation trends, and interactive drill-downs.
